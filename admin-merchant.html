🏪 แผงจัดการคำขอผู้ประกอบการและรางวัลออนไลน์

จัดการคำขอผู้ประกอบการ (`merchant_requests`), สร้างของรางวัลออนไลน์ (`campaigns`) และปิดรายการแลกรางวัล (`reward_claims`)

กำลังตรวจสอบเซสชัน...
ชื่อร้านค้า ประเภท / พื้นที่ ช่องทางติดต่อ User ID / ชื่อ หมายเหตุ วันที่ส่ง จัดการ
กำลังโหลดข้อมูล...

➕ สร้างของรางวัลออนไลน์ใหม่ (บันทึกลงตาราง campaigns)

📋 รายการแคมเปญรางวัลออนไลน์ในระบบ
รูป ชื่อรางวัล / ประเภท พอยต์ / โควตา ผู้ให้รางวัล ช่วงเวลา สถานะ จัดการ
กำลังโหลดรายการของรางวัล...
รหัสคำขอ ผู้แลกรางวัล รางวัลที่แลก บัญชีปลายทาง สถานะ / หลักฐาน วันที่ขอ จัดการ
กำลังโหลดคำขอแลกของรางวัล...

📤 ยืนยันการส่งของรางวัลและแนบหลักฐาน

* ต้องแนบรูปหลักฐาน หรือกรอกข้อความ/รหัสอ้างอิงอย่างน้อย 1 อย่างก่อนจึงจะปิดรายการได้
